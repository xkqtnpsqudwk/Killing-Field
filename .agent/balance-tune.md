# balance-tune

My2DEngine 밸런스 수치를 안전하게 조정하는 가이드.

## 핵심 원칙

**모든 수치값의 진실의 원천은 `Game/Config/GameConfig.cs`**  
코드 어디에도 매직 넘버를 직접 쓰지 않는다.

## 주요 수치 카테고리별 위치

### 무기 스탯
| 항목 | 위치 |
|---|---|
| 데미지, 쿨다운, 사거리, 스프레드 | `GameConfig` (무기별 상수) |
| 업그레이드 등급 보너스 | `GameConfig` (White+1%~Red+5%) |
| 탄약 최대값 | `GameConfig` |

### 플레이어 스탯
| 항목 | 현재값 |
|---|---|
| 기본 체력 | 100 |
| 이동속도 | 2.5 tiles/s |
| 질주 배율 | 1.5× |
| 대시 거리/시간/쿨다운 | 2.0t / 0.20s / 5.0s |
| FOV 기본/범위 | 80° / 60°~90° |
| 마우스 감도 | 0.003 rad/px |

### 적 스탯
- 기본값: EnemyCatalog에 정의
- 난이도 스케일링: 한 전투 층 클리어시 HP +0.4%, 데미지 +0.3%, 속도 +0.5%
-                  보스 클리어시 HP +4%, 데미지 +3%, 속도 +1.5%
-                  휴식 스테이지는 스케일링에 포함하지 않는다
- 수정 위치: `GameConfig` 또는 `EnemyCatalog`

### 물리·충돌
| 항목 | 값 | 주의사항 |
|---|---|---|
| 플레이어 반지름 | 0.1 tiles | 줄이면 벽 관통 위험 |
| 충돌 스텝 크기 | 0.025 tiles | 늘리면 벽 관통 발생 |
| 문 열리는 시간 | 0.85s | |

## 조정 시 주의사항

1. **충돌 스텝 크기(`CollisionStepSize = 0.025f`)는 절대 크게 늘리지 말 것** — 큰 이동값은 벽 관통 유발
2. **카메라 방향 변경 시 `Camera.Plane`도 반드시 갱신** — Direction과 수직 유지 필수
3. **문 상태 확인 시 progress 값 참조** — 완전히 열리면 타일이 0으로 전환됨
4. **업그레이드 매트릭스 인덱스 범위** — `weaponUpgradeLevels[5, 8]` 초과 금지

## 빠른 수정 절차

1. `GameConfig.cs` 열기
2. 해당 상수 수정
3. 빌드 후 즉시 인게임 체감 확인
4. 극단값(0, 음수, 매우 큰 값) 입력 방지 — 물리/렌더링 예외 유발 가능

## 현재 밸런스 패스 기준선

현재 플레이 체감상 난이도는 목표치에 가깝기 때문에, 조정은 바로 수치를 바꾸기보다 먼저 분포와 회귀를 확인한 뒤 필요한 경우에만 한다.

확인 명령:

```powershell
dotnet run --project My2DEngine.SmokeTests\My2DEngine.SmokeTests.csproj -- --balance-snapshot
```

리포트가 확인하는 항목:

- 플레이어 체력/보호막, 적 성장, 생존 방, 열쇠 표적, 독안개 핵심 수치
- 초반/중반/후반 방 타입, 목표, 위험, 위험도 분포
- 보스 클리어 단계별 상위 적 출현 분포
- 카드 선택지 수, 카드 상점 가격, Luck별 상점 카드 등급

조정 우선순위:

1. 실제 플레이에서 반복적으로 과하거나 약하게 느껴지는 구간만 조정한다.
2. 수치 변경 전후 `--balance-snapshot` 결과를 비교한다.
3. 기능 회귀 확인은 일반 스모크 테스트를 같이 돌린다.
